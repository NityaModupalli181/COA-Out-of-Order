# results/

This directory contains raw benchmark output files generated by `run_all.py`.

## Files generated after running the benchmark

| File | Generated by | Contents |
|------|-------------|----------|
| `results.json` | `benchmark.py` | Full benchmark: tok/s, α, speedup per config × n |
| `mamba_results.json` | `mamba_draft.py` | Mamba-130m vs GPT-2 Small comparison |
| `acceptance_logs.json` | `benchmark.py` | Per-round token acceptance logs |
| `beta_measurements.json` | `models.py` | β timing measurements per model |

## How to reproduce

```bash
# Full benchmark (~40 min on GTX 1650)
python main.py

# Benchmark only, skip Mamba (~25 min)
python main.py --bench

# Mamba comparison only (~10 min)
python main.py --mamba

# Smoke test (~5 min)
python main.py --quick
```

## Evidence levels

- **E1 (Measured)**: P1 (GPT-2 Small → GPT-2 XL) — all numbers in results.json
- **E2 (Proxy)**: P3 (Mamba-130m → GPT-2 XL) — numbers in mamba_results.json
- **E3 (Projected)**: P2, P4 — computed analytically, NOT in results files

See `configs/` for full parameter definitions per pair.
